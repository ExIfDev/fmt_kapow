# fmt_kapow
Script for Noesis Viewer/unpacker for TotalOverdose.


Support for: .map, .main, .playerdata, .mission, .submap, .model

.kpwtex is an intermediate texture format created specifically for this addon.

Full Animation support

designed for the CD version of the game, GoG may have issues


# installation

1) Download Noesis (https://richwhitehouse.com/index.php?content=inc_projects.php&showproject=91)
2) Download fmt_kapow.py and copy it to "noesisv4474\plugins\python"

# Usage
1) use naztozip.exe to convert blocks.naz to blocks.zip (just drag and drop blocks.exe onto naztozip.exe)
2) extract blocks.zip
3) Open Noesis navigate to the exracted folder
4) Select an asset of interest (eg. overdose.main)
5) Doubleclick on overdose.main and it will show an extraction prompt, click Extract
6) Navigate to the newly created folder (eg. overdose_files)
7) Open any .model or .kptex to view it
